# Mac Pulse — CPU and Memory Monitor

A native macOS app for understanding CPU activity, memory pressure, and processes. Includes a SwiftUI live dashboard, menu bar panel, and WidgetKit snapshots.

See [README.md](README.md) for startup/architecture and [docs/NEXT_STEPS.md](docs/NEXT_STEPS.md) for validation/manual checks. The original Python terminal prototype is retained for reference.
