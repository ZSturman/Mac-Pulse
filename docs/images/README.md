Keep representative real captures here. Do not substitute mockups or generated images for the running app.

2. Select Overview, use a window around 1160 × 850 points, and scroll to show the metric cards and process leaders. Avoid other windows/private desktop content.
3. Press **Command-Shift-4**, then Space, and click the app window. Move the capture here as `mac-pulse-overview.png`.
4. Add a medium Mac Pulse widget through desktop → Edit Widgets. Capture just it as `mac-pulse-widget.png`, with readings and sample time visible.
